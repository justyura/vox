02 / SYSTEM DESIGN

为计算与请求
选择不同的节奏。

API 保持轻量，文件通过预签名 URL 直达对象存储；计算密集型 Worker 从队列按需取任务。这种边界让计算能力可以独立扩展。

01

传输效率

大文件绕过 API 服务，减少带宽和内存压力。

02

异步解耦

RabbitMQ 吸收流量峰值，用户请求不必等待模型执行。

03

计算隔离

whisper.cpp Worker 可以独立部署、恢复并在未来弹性扩容。
